# Portfolio-Optimization-and-Risk-Analysis
  ## Portfolio Optimization & Risk Analytics Platform

• Developed a portfolio optimization system using **Python, Pandas, NumPy, SciPy, and Yahoo Finance data** to evaluate risk-adjusted investment strategies across equities, bonds, gold, and real estate assets.

• Implemented Monte Carlo simulations of **10,000+ portfolios** and identified optimal asset allocations using Modern Portfolio Theory and Sharpe Ratio maximization.

• Built risk analytics features including **covariance analysis, efficient frontier visualization, Value-at-Risk (VaR), and long-term portfolio growth projections**.

• Delivered interactive insights that supported **data-driven investment decisions** through quantitative modeling and financial analytics.
